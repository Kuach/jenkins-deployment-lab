# Website Deployment Automation with Terraform and Jenkins

This repository contains an academic lab report about provisioning cloud infrastructure and deploying a simple website.

## Topics covered

- Terraform configuration examples for Google Cloud infrastructure
- A Debian virtual machine and an Apache web server
- Jenkins pipeline stages for retrieving and deploying website files
- GitHub webhooks as deployment triggers

## Repository format

The work is documented as a university lab report in Ukrainian. Terraform and Jenkins examples are embedded in the report; this repository does not include standalone configuration files or a runnable deployment pipeline.
